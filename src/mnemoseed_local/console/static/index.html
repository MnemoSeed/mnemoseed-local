        Config

        Edit one key at a time. Every write is validated, versioned, audited, and applied to the running daemon — the settings DB is primary, config.toml is its mirror.

        Restart required — some keys only take effect after the daemon restarts.

        Version history

        GET /api/v1/config/versions

        Every write, rollback, and boot import is a versioned record. Restore turns an earlier value into a new version — nothing is ever deleted.

        Profiles

        Identity namespaces for memory isolation. The default profile is implicit and needs no row. Archiving never deletes and never unbinds.

        Archived never deletes, never unbinds — archived profiles keep their row and their bindings; they just stop receiving new captures.
